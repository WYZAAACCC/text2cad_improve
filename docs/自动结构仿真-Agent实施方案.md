# 自动结构仿真 Agent 实施方案

日期：2026-09-10

## 1. 目标与不可退让的原则

目标是让 Agent 使用真实 CAD 拓扑、通用计算工具和本地 ANSYS Mechanical APDL，
完成涡轮盘的旋转-温度-榫槽载荷结构分析。系统不能把某个族、某个榫槽面索引或
某条温度/力公式写死成专用模板。

硬性边界：

- 普通数学、向量、单位换算可以调用通用工具或沙箱；
- 榫槽承力面必须由 Agent 从持久拓扑角色和几何事实中选择；
- 转速轴、温度边界/温度场、叶片力大小与方向必须由 Agent 在显式输入或可用
  专家参数下决定，并要求人工确认；
- 求解器只能接收 Agent 生成的显式载荷/边界集合，不能看到“D19 榫槽模板”
  这类专用生成器；
- 代码只负责接口、单位、映射、物理守恒和审计，不能替代 Agent 选面或填载荷；
- 任何真实数值输入（叶片力、温度、材料、转速）没有来源时，状态必须是
  `needs_input`，不能猜。

## 2. 物理问题的正确定义

目标问题不是一个 Fluent 流体 CFD 算例，而是带预应力的稳态热-结构问题：

1. 旋转：整个盘体绕从 CAD 拓扑识别的轴对称旋转，产生离心体积力；
2. 温度：温度场可以来自已给定的节点/区域温度，或来自一次稳态热传导求解；
3. 榫槽载荷：叶片离心力经榫槽接触面传递，必须施加到 Agent 选出的承力面；
4. 约束：至少消除刚体运动，同时保持循环对称或全盘约束物理含义明确；
5. 结果：应力、位移、反力/反力矩、温度范围和守恒检查。

本方案不把它宣称为叶片-榫槽接触非线性分析，除非后续显式增加接触求解和
摩擦/间隙校验。

## 3. 工作包

### W1 通用拓扑事实与 Agent 选面

交付：

- 列出 `face_role`/`edge_role`，按 namespace、feature、key 返回；
- 解析任意角色到实际 `TopoDS_Face`，不按 STEP face index；
- 返回通用几何事实：面积、质心、柱坐标、面类型、法向、平面/圆柱轴、
  包围盒、边数；
- 给 Agent 提供候选搜索和事实查询工具；
- Agent 自主输出承力面角色集合及选择理由；
- 不创建“哪个角色是榫槽承力面”的硬编码映射。

### W2 网格与持久面到网格映射

交付：

- Agent 选择扇区角或全盘范围、网格尺寸和局部加密；
- 用通用 sector/domain mesh 工具生成网格；
- 将 Agent 选中的 TopoDS 面与网格边界做可审计映射（面积、质心、法向/
  解析曲面参数，多候选必须拒绝）；
- 输出每个选中面的 ANSYS 节点集/面集；
- 映射必须有唯一性和误差证据，不能按最近标签猜测。

### W3 通用载荷与温度程序

交付：

- 旋转体载荷：Agent 提供轴原点、方向、角速度；
- 面温度：Agent 提供角色集合、温度值或由通用表达式计算；
- 区域温度：Agent 通过通用表达式在节点上生成 T(x,y,z)，表达式和参数
  必须留档；
- 面力/压力/牵引：Agent 提供承力面集合、总力向量或分布方式，通用工具
  负责单位换算和均分/面积加权；
- 约束：Agent 提供角色集合和自由度，不自动猜固定面。

### W4 ANSYS 18.1 执行与结果

交付：

- 复用 `AnsysAPDLRunner`，不调用盘体模板；
- 由 W3 的中性载荷程序生成 APDL；
- 静力/热-结构求解，保留 `.inp/.out/.rst`；
- 结果至少包含最大/最小温度、最大位移、最大 von Mises、榫槽区域应力和
  反力；
- 回到顶层检查总施加力、反力平衡、单位、温度范围和旋转载荷数量级。

### W5 真实 Agent 编排

流程：

```text
用户需求
  -> Agent 检查几何与拓扑角色
  -> Agent 选择承力面/温度区域/旋转轴
  -> Agent 输出结构化 StructuralIntent
  -> 人工确认硬参数
  -> 通用工具生成网格与载荷
  -> ANSYS 求解
  -> Agent + 守恒校验结果审查
```

### W6 样本与验收

首先处理 D19（60 个榫槽）和 D29 等含复杂轮缘族的真实输入。每个样本必须
保留：

- 角色选择集与理由；
- 面几何事实；
- 网格到面的映射误差；
- 温度/转速/叶片力输入来源；
- 施加力、反力、力矩和温度范围；
- ANSYS 原始文件与结果摘要。

## 4. 当前第一步

已在 `_structural_experiment/` 建立独立实验区，并实现通用拓扑角色事实工具
`role_facts.py`。它只解析角色和返回几何事实，不包含榫槽、温度场或载荷模板。
后续 Agent 将在持久打开的 OCAF 会话中使用这些工具，避免每次调用重新加载
XBF。

## 4.1 已定位的 D19 阵列拓扑根因

对 `n_pattern_cutters` 的真实结果形状做 `TopAbs_SOLID` 拆分后，得到 **60 个
独立 TopoDS 实体，每个 68 个面**，体积均为 `15460.86194 mm3`：

- solid 0 位于原点附近，是阵列前保留的基准工具；
- solid 1 的质心为 `r=241.0959 mm, θ=6.000°`；
- solid 2 的质心为 `r=241.0959 mm, θ=12.000°`；
- 其余实体按 6° 间隔沿轮缘分布。

这说明原始 face-role 清单不是“按槽分组”的。第一次 Agent 只查询前 68 个面角色
并提交的结果跨越了多个阵列实体，不能直接映射到 3°-9° 的单槽扇区。Agent
本身没有错在算术，而是当前工具没有暴露“哪个面属于哪个真实 TopoDS 实体”。

修正方向：

1. Agent 先通过 `TopAbs_SOLID` 连通实体选择要加载的一个槽实体；
2. 只对该实体内部的 68 个 TShape 面返回几何事实；
3. Agent 再根据面法向/位置选择承力面；
4. 最后用 TShape 精确身份把这些面关联回持久 face-role，作为审计身份。

该修正不需要榫槽专用模板，也不允许按 `face_000/face_001` 这类编号猜面。

## 5. 需要人工确认的硬参数

以下量不能由代码替用户编造，缺省时系统必须停在 `needs_input`：

- 每个榫槽的叶片等效离心力大小和方向，或叶片质量、重心半径及转速；
- 温度来源：测点/区域温度、热边界条件，或允许的稳态热传导模型；
- 转速与旋转轴；
- 约束方式；
- 材料温度相关属性及来源；
- 是否只做线弹性静力，还是需要接触/塑性/疲劳。

## 6. 当前实现状态

截至 2026-09-10，独立结构实验模块已经形成可运行链路：

1. Agent 先调用 `list_features` 自主发现 CAD history 中的重复轮缘槽特征；
2. Agent 从真实断开 TopoDS 实体中选择 3°-9° 扇区内的单个槽实体；
3. Agent 只接收该实体真实面事实，并自主提交承力面索引；
4. 精确面到扇区网格映射为 8 个面、每面 253 节点，共 2024 个节点，
   零重叠、零平面距离误差；
5. `StructuralIntent` 对转速、温度、材料、叶片载荷、约束和来源逐项留痕；
6. 缺少叶片载荷时，真实 LLM 返回 `needs_input`，不会用猜测值继续；
7. 中性载荷物化器按面面积分配等效承力面节点力，并复核合力与绕轴力矩；
8. 本地 ANSYS 18.1 已完成一次端到端求解和后处理。

近零叶片载荷对照中，新中性管线最大 von Mises 为 1124.595 MPa，旧非 Agent
基线为 1123.468 MPa，相对差 0.1003%。这说明相同的转速、温度、材料和约束
条件下，新实现没有发生求解退化；加入显式合成的 10 kN 每槽载荷后，最大
von Mises 升至 1151.076 MPa。

该实现位于 `_structural_experiment/`。它不导入
`apdl_template_3d.py`，不读取 golden face list，也不使用确定性盘体模板。

当前端到端冒烟使用显式标注的合成 10 kN 每槽载荷，因此结果状态为
`synthetic_or_unconfirmed_pipeline_validation`。真实工程算例仍需提供并确认
叶片载荷、温度/材料来源和约束。
