## 一、背景与目标

**项目**：面向航空发动机涡轮盘的自然语言参数化 CAD 建模（论文），核心是构建领域数据集 **NL2DiskCAD** 并训练领域模型 **AeroDisk-LLM**。

**数据集定位**：NL2DiskCAD 不是简单的"自然语言—CAD 文件"配对，而是覆盖涡轮盘设计意图、特征图、中间表示、确定性 CAD 执行、错误修复和模型质量检查的**复合数据集**。

**当前阶段目标**：完善数据收集基础设施，使"候选采样 → 生成 → 过滤 → 标注 → 四类任务 → 隔离切分"各环节能**正确、完整**地采集论文要求的数据。生成层采用**确定性参数化模板**（不依赖 LLM 建模能力），LLM 只用于生成 Gen 任务的三类描述与多 agent 训练。

## 二、论文数据集要求（权威规范，见论文附件）

### 2.1 S/Y 元组

**S 元组**（每个完整几何样本至少包括）：
```
S = {T 需求文本, P 参数表, Gf Feature Graph, Dg Disk-G-CAD, CCAD 执行序列,
     MBRep 原生B-rep, MSTEP STEP模型, Rquality 质量报告, Rregen 再生测试}
```
**Y 元组**（系统输出）：`Y = (Gf, Dg, MCAD, MSTEP, Rq, L日志)`

**含榫槽模型额外保存**：单榫槽二维轮廓、单槽轮缘节段模型、周向阵列模型、榫槽参数（齿数/齿面角/槽深/喉宽/圆角）、相邻榫槽剩料检查、STEP 回读轮廓尺寸一致性。

### 2.2 32 设计族（6 类，20 训练 / 4 验证 / 8 留出）

| 类别 | 训练 | 验证 | 留出 | 合计 |
|---|---|---|---|---|
| 基础轮毂-腹板-轮缘盘 | 3 | 0 | 1 | 4 |
| 中心孔与周向孔阵列盘 | 3 | 1 | 1 | 5 |
| 环槽与减重结构盘 | 3 | 1 | 1 | 5 |
| 标准枞树形榫槽盘 | 5 | 1 | 2 | 8 |
| 榫槽-孔阵列-环槽耦合盘 | 4 | 1 | 1 | 6 |
| 复杂轮缘过渡与榫槽组合盘 | 2 | 0 | 2 | 4 |
| **合计** | **20** | **4** | **8** | **32** |

### 2.3 参数范围（附件四，非型号化范围）

- **总体**：外径 360-760、中心孔直径 50-200、轴向最大厚度 30-130
- **主体轮廓**：腹板最小厚度 6-32、轮缘径向高度 25-95、轮毂径向高度 25-100
- **孔阵列**：孔数量 6-36、孔径 4-26、孔分布半径 80-310
- **环槽**：槽宽 4-28、槽深 2-20
- **局部修饰**：倒角 0.5-8、圆角半径 0.5-18
- **榫槽**：周向数量 24-96、齿数 2-4、径向总深 12-45、喉部宽度 4-18、最大切向宽 8-32、单级齿高 2-10、齿面角 25-55°、齿根圆角 0.5-4、槽底圆角 1-8、槽口倒角 0.5-5、轴向贯穿长 20-90、相邻剩料 2-12

### 2.4 几何约束体系（附件五）

- 孔越界：`rp + dh/2 + cb ≤ rb`
- 相邻孔间距：`2·rp·sin(π/nh) − dh ≥ ch`
- 榫槽节距：`ws + 2·cs ≤ ps = 2π·rs/Ns`
- 榫槽深度：`hs + mr ≤ tr`（轮缘可用径向厚度）
- 轮廓闭合/无自交/无退化短边/齿根圆角可放

### 2.5 规模与过滤

```
102,400 候选 → 5 级过滤 → 49,920 有效模型 → 217,920 任务
（Schema 86.0% → 参数几何 72.0% → Compiler 60.5% → 几何质量 53.5% → 再生STEP 48.75%）
```

**四类任务**：
- **Gen** 149,760 = 49,920×3 描述（中文简洁/中文工程/英文混合）+ SER 七步标注
- **Edit** 24,960（单参 8,320 + 耦合 8,320 + 特征增删 5,120 + 保持约束 3,200）
- **Repair** 30,720（7 类错误：Schema/节点依赖/参数单位/孔环槽/榫槽/布尔拓扑/再生STEP）
- **MCP** 12,480（单工具/多工具/新工具异常边界）

### 2.6 隔离原则（5 层）

设计族、榫槽母型、Feature Graph 哈希、Disk-G-CAD 文档哈希、B-rep 几何指纹；同几何模型的 Gen/Edit/Repair/MCP 必须同集合。

## 三、当前系统架构

### 3.1 生成层（原生两阶段）

**确定性参数化模板** `_param_experiment/param_templates.py`：
```
plan(params)                 → Agent A 输出（AgentDesignPlan：gcad_skeleton 骨架 + profiles 参数声明）
disc_profile()/slot_profile()→ Agent B/C 输出（盘体 12 点 R-Z 轮廓 / 榫槽 2×(2+4n+3) 点轮廓）
assemble()                   → 完整 llm_raw（按 kind_hint 契约填充 points）
build(params)                = plan() → B/C 轮廓 → assemble
```

**LLM 生成层**（推理端/对比）`app/text-to-cad/server/agentic_l2.py`（AGENTIC_L2=1 启用）：
- Agent A：整体设计（需求 → 骨架 + profiles）
- Agent B：盘体轮廓（参数 → 12 点）
- Agent C：榫槽轮廓（参数 → 榫槽点）

**类别映射**：
- 榫槽类（slot/coupled/complex_rim）：sketch_profile 盘体 12 点 + 榫槽 cutter + composition 布尔
- axisym 类（basic/hole/groove）：axisymmetric 单组件（revolve stations → bore → 孔/环槽 → chamfer）

### 3.2 数据基础设施脚本（`_param_experiment/`，全部独立，不碰主流程 src）

| 脚本 | 职责 |
|---|---|
| `candidate_sampler.py` + `sampling_constraints.py` | 三区候选采样（可行/边界/不可行）+ 论文几何约束纯函数 |
| `param_templates.py` | 确定性参数化模板（原生两阶段 plan/B/C/assemble） |
| `build_agent_data.py` | 多 agent 训练数据（L1 路由/A 设计/B 盘体/C 榫槽，含系统+用户 prompt） |
| `run_batch.py` | 批量执行（断点续跑/失败隔离/可选并发） |
| `run_enrich.py` | 标注（归一化参数/隔离键/labels/约束/指纹） |
| `run_filter.py` | 5 级级联过滤（cumulative_level） |
| `run_index.py` / `run_split.py` | 索引 + 隔离切分 + 捆绑验证 |
| `run_regen.py` | Rregen 再生（roundtrip/dims_stable/solid_valid） |
| `run_edit_tasks.py` | Edit 构造器（单参/耦合/特征增删/保持约束） |
| `run_repair_tasks.py` | Repair 构造器（5 类注入 + 真实提取 + STEP 回读） |
| `run_mcp_tasks.py` | MCP 构造器（5 类序列） |
| `run_descriptions_llm.py` | LLM 三描述 + 参数一致性验证 |
| `export_mid_models.py` | 含榫槽中间模型导出（单槽轮廓/工具体/阵列） |
| `audit_collection.py` | 采集正确性核查（字段覆盖/标注/隔离） |
| `design_families.py` | 32 设计族种子定义（D01-D32） |

### 3.3 主流程落盘字段

`app/text-to-cad/server/output/<task_id>/`：
request.json(T)、prompt_full_l1/l2(L)、llm_raw/raw_fixed(Dg)、canonical_ir(Gf+CCAD)、output.step(MSTEP)、output.brep(MBRep)、validation_report(Rquality)、regen_report(Rregen)、pipeline_log/tool_calls(L)、dataset_enrich(P)、descriptions、mid_models/（含榫槽盘中间模型）

## 四、数据收集流程（端到端）

```
1. candidate_sampler     32 族 → 三区候选（参数落论文范围 + 几何约束）
2. run_batch --template   模板生成 llm_raw（确定性）→ validation/repair → MCP 门
3. run_filter             5 级级联（L1-L5，有效模型判定）
4. run_enrich             标注（归一化/隔离键/labels/约束/B-rep 指纹）
5. run_index / run_split  索引 + 隔离切分 + 捆绑验证
6. 任务构造               Edit/Repair/MCP 样本（每有效模型）
7. run_descriptions_llm   Gen 3 描述（中文简洁/中文工程/英文混合）+ SER
8. export_mid_models      含榫槽盘中间模型（单槽轮廓/工具体/阵列）
9. build_agent_data       多 agent 训练数据（L1/A/B/C，含 prompt）
10. audit_collection      采集正确性核查（字段覆盖/标注/隔离）
```

## 七、已知问题与缺口

### 7.1 模板设计缺口（专家诊断重点）

| 类别 | 缺口 | 论文要求 |
|---|---|---|
| **环槽与减重结构盘** | 当前只有环槽（cut_annular_groove），**缺减重孔阵列/冷却孔阵列/轴向或径向局部切槽/局部减重结构** | 附件 2.2：减重孔/冷却孔/局部切槽/局部减重 |
| **复杂轮缘过渡盘** | 当前标准 12 点直线轮廓（仅 rim 参数大），**缺圆弧段/样条段曲线轮缘过渡** | 附件 2.1：主体子午轮廓由直线段、圆弧段和样条段组合构成；benchmark 要求"新型轮缘过渡轮廓" |
| 盘型数据 | 孔/环槽/耦合/复杂轮缘盘**未批量执行**（模板已验证可生成） | 32 族 20 族需产出 |

### 7.2 历史数据限制（不可回溯）

- 早期 uuid 任务 L 日志/T 全文不可恢复（运行时未记录，已透明标注）
- 6 早期任务 canonical_ir 不可生成（op 漂移/root_node 缺）
- 早期任务 MBRep 为 STEP 回读版（brep_source 已标注）

### 7.3 其他

- STEP 回读仅比体积 + bbox 外径/轴厚（0.05mm），中心孔需截面分析（未做）
- Repair 第 4 类（孔环槽几何错误）无数据（无孔环槽盘）
- MCP 第 3 类（新工具/异常/边界）数据覆盖少（仅 1 任务）

## 八、种子设计族现状与构建方向

### 8.1 现状（design_families.py，32 族定义完成）

每族：`{category, split, od/bore/thick/hub/rim, features}`。参数全部落在论文范围。

| 族 | 参数（示例） |
|---|---|
| D01-D04 基础 | od 460-700, bore 110-180, thick 70-110 |
| D05-D09 孔 | holes 12-30, pcd 200-270, hdia 10-18 |
| D10-D14 环槽 | grooves 1-3, gw 8-24, gd 6-14 |
| D15-D22 榫槽 | slots 48-96, teeth 2-4, depth 24-42 |
| D23-D28 耦合 | 榫槽+孔+环槽组合 |
| D29-D32 复杂轮缘 | rim 36-48（厚轮缘） |

### 8.2 待构建方向（专家建议重点）

1. **减重结构盘**：环槽类补减重孔阵列（cut_circular_hole_pattern）、冷却孔阵列（小孔径）、轴向/径向局部切槽（cut_rim_slot_pattern，已注册）、局部减重结构
2. **曲线轮缘过渡盘**：复杂轮缘类用 add_arc_segment（sketch_profile 已注册圆弧段 op）实现圆弧轮缘过渡，替代直线 12 点；benchmark 需要"新型轮缘过渡轮廓"
3. **参数采样规模**：当前每族 ~10 候选（三区），论文终态 ~4,267/族（102,400 候选）——需扩展采样器生成规模
4. **盘型批量产出**：对 20 个非榫槽盘型族批量执行模板生成（验证过的确定性模板）
5. **后训练**：用 agent_data（L1/A/B/C 样本）做 AeroDisk-LLM 的 LoRA/QLoRA 训练

## 十、专家诊断重点与建议

请专家重点诊断：

1. **模板设计完整性**：groove 类减重结构（减重孔/冷却孔/局部切槽/局部减重）与 complex_rim 类曲线轮缘过渡（圆弧段 add_arc_segment）的参数化实现方案

3. **种子设计族扩展**：如何用 32 族种子覆盖论文全部特征范围（含减重结构、曲线轮缘、双排孔阵列、榫槽与环槽耦合等）
4. **数据正确性**：STEP 回读轮廓尺寸一致性（中心孔截面分析）、Repair/MCP 全类别数据覆盖
5. **后训练数据**：agent_data（L1/A/B/C 四角色样本）是否满足 AeroDisk-LLM 的多智能体训练需求
