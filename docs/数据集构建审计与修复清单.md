## 四、关键审计发现（按严重度排序）

### 🔴 F1：字段覆盖严重不平衡——63/69 早期任务缺后加字段（最高优先级）
69 个任务中仅最近生成的 6 个（`verify_br/ds/la` + `gen_*` 3 变体）有全部字段。早期 63 个（`mon_sweep_*`、16 位 hex）缺：
- `request.json`（T 全文）、`canonical_ir.json`（Gf/CCAD）、`pipeline_log.json`/`tool_calls.json`（L）
- `output.brep`（MBRep）、`regen_report.json`（Rregen）

**原因**：这些落盘是基础设施演化的后加字段，早期测试任务未回溯。

**修复方向**：
- `canonical_ir.json`：可从 `raw_fixed.json` 重新 canonicalize 生成（脚本：读 raw → `RawGcadDocument.model_validate` → `canonicalize` → model_dump_json 落盘）
- `output.brep`：可从 `output.step` `importStep` → export 生成（已证可行）
- `request.json`（T 全文）：早期任务原始文本可从 `param_sweep_test.CASES`/`param_sweep_parallel` 的 `_text` 重建（任务名编码组合，如 `mon_sweep_g1_baseline`→G1）；16 位 hex 任务无法重建 → 标记缺失
- `pipeline_log.json`/`tool_calls.json`（L 日志/轨迹）：**无法回溯**（运行时数据未记录）→ 需重跑或标记"无日志"

### 🔴 F2：gen 变体任务缺 descriptions.json（66/69）
`run_gen_variants.py` 生成变体后未跑 `run_descriptions.py`（3 个 `gen_*` 任务无描述/SER）。修复：变体后处理链加 run_descriptions。

### 🟠 F3：fingerprint 仅 3/69
依赖 `output.brep`（仅 3 个新任务有）。修复后（F1 回溯 brep）覆盖提升。

### 🟠 F4：regen_report 仅 1/69
Rregen 只对 `mon_sweep_q2` 跑过。需对有效模型批量跑 `run_regen.py`（LLM 无关，确定性重建 21-49s/任务）。

### 🟠 F5：en_mixed 描述变体 LLM 生成不稳定
`run_gen_variants` 验证：cn_param/cn_semantic 变体有效，en_mixed 变体 MCP 门退化（check_degenerate_geometry）。这是论文 en_mixed 评价点的真实挑战。修复方向：优化 en_mixed 描述模板（可能需纯英文精简）或数据集构建时观察。

### 🟠 F6：32 设计族种子未定义
`design_family_id` 目前是 G1-G5/custom（测试参数扫描系列），非论文 32 设计族（20 训练/4 验证/8 留出）。`family_split.json` 是演示分配。**修复**：定义种子设计族（母型参数模板，从 COMBINATIONS A-D + 论文 6 类盘型扩展），填充 FAMILY_REGISTRY + family_split。

### 🟡 F7：5 级过滤为独立诊断，非论文级联
`run_filter.py` 每级独立判定（相对初始），论文是严格级联（L5⊂L4⊂...）。级联语义需在批量管线（run_batch --run）生成时实现（逐级淘汰，不生成被淘汰的）。

### 🟡 F8：Edit 类型未全覆盖
论文 Edit 4 类（单参数 ✓ / 耦合参数 ✓ / 特征增删替换 ✗ / 约束保持调整 ✗）。缺特征增删替换（需 IR 结构编辑）+ 约束保持调整（保持剩料/轮缘厚度联动）。

### 🟡 F9：Repair 7 类错误缺 2 类
当前 5 类（Schema/节点依赖/参数/节距剩料/布尔拓扑 runtime 记录）。缺孔阵列/环槽（当前盘无孔 op，需含孔设计族）+ STEP 回读（需注入后 STEP 不一致的确定性复现）。

### 🟡 F10：MCP 为确定性调用，无 LLM agentic 轨迹
`run_mcp_tasks.py` 确定性调工具（expected_args 明确，评价参数绑定有利），但论文 MCP 任务语义是"LLM 将 NL 请求转为工具序列"。真实 agentic 轨迹（mcp_runner/mcp_server）未接入样本生成。

### 🟡 F11：不可行样本错误码未按 7 类归码
`run_infeasible.py` 16 个样本的 error 是字符串（"MCP quality gate failed..."），未按论文 7 类错误枚举归码。

### 🟡 F12：级2 过滤的 check_slot_depth_and_rim 硬编码 x>150
`check_slot_depth_and_rim` 硬编码 `x>150`（KT787 特定），跨设计族误判。`run_filter.py` 已用 CORE_SUBSET 排除，但构造器/其他路径需注意。
