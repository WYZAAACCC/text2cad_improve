# D19 自动结构仿真验证报告

日期：2026-09-10

## 1. 验证目标

验证 Agent 驱动的旋转-温度-榫槽载荷结构分析链路能够在真实 D19 CAD lineage、
真实 OCAF 拓扑和本地 ANSYS 18.1 上完整运行，同时满足以下边界：

- 不调用旧盘体 APDL 模板；
- 不读取 golden 面或 golden 载荷；
- 不硬编码榫槽面索引；
- 缺少物理硬输入时停止在 `needs_input`；
- 对所有输入来源、载荷分配和求解产物留下审计记录。

## 2. 输入

- CAD bundle：`_cfd_experiment/input/lineage/D19`
- 扇区网格：`_structural_experiment/work/D19_mesh/mesh.inp`
- 网格规模：28,239 节点，15,289 个 SOLID187 二阶四面体
- 真实特征结果：`n_pattern_cutters`
- Agent 选中实体：3°-9° 扇区内的 `solid_index=1`
- Agent 选中面：`5, 14, 22, 30, 42, 50, 58, 66`
- 面到网格映射：8 个面各自 253 节点，共 2024 个去重节点
- 映射重叠：0
- 每面最大平面距离：0 mm

## 5. 独立回归

在同一网格上使用近零合成叶片载荷隔离盘体离心与温度场，并与旧的非 Agent
APDL 基线比较：

| 实现 | 最大 von Mises |
| --- | ---: |
| 新中性管线 | 1124.595 MPa |
| 旧基线 | 1123.468 MPa |
| 相对差 | 0.1003% |

该结果表明在相同转速、温度、材料和约束下，新实现没有发生明显求解退化。
启用 10 kN 每槽合成载荷后，峰值增至 1151.076 MPa。

## 7. 当前限制

- 叶片载荷采用等效节点力，不是接触面法向压力加摩擦的非线性接触模型；
- 当前材料模型为温度相关线弹性，不含塑性、蠕变和疲劳；
- 当前是单槽循环扇区，不分析整圈盘体与多叶片装配偏差；
- 合成载荷结果不能用于强度结论或设计认证。
