## 一、目标与方法

为论文"面向航空发动机涡轮盘的自然语言参数化 CAD 建模"生成枞树形榫槽（fir-tree slot）的**确定性参数化几何**（参考几何，非适航件）。采用：

1. **半边轮廓生成 → 镜像 → 闭合**（`fir_tree_slot2d.py`，依据 `docs/榫槽伪代码.md` §20-21）
2. **尖角骨架 → 圆角相切**：先建理论尖角线，再对齿顶/齿根/过渡用 `CreateFillet`（切点距 = R/tan(φ/2)）
3. **主实现**（`param_templates.slot_profile`）：角度驱动齿面角 + 齿根共线 + 顶点 fillet，最终经 validation/runtime/MCP 门产出 STEP

## 二、当前实现架构（param_templates.py）

### 2.1 slot_profile() — 轮廓点生成

```python
slot_profile(teeth, depth_mm, mouth_half, neck_half, lobe_half,
             bottom_half, tfa_deg=80.0, ufa_deg=70.0) -> [points]
```

- **坐标**：x 径向（0 = 槽口 → −depth = 槽底），y 半宽。上侧 `2+4×teeth+3` 点 + 下侧 y=0 镜像。
- **每齿 4 点**：外斜面升（齿顶）→ 齿顶平台 → 内斜面降（齿根）→ 连接线。
- **齿面角角度驱动**（P6 修复）：斜面 x 跨度 `dx = Δy/tan(θ)`，θ = Tfa（外/承力面）/ Ufa（内/非工作面），默认 80°/70°（mon 实测）。
- **齿根共线斜线** `y_neck(x)`：齿根点（内斜面降 + 连接线）沿一条斜线排列（线性穿过楔入点与最后齿根），斜率 ~0.095（5.4°）。
- **neck/lobe**：neck_half=1.1×throat（4.4）、逐齿递减 0.25×throat（下限 1.5）、lobe=2.25×throat（9.0）、逐齿衰减 0.25×throat。
- **短边修正**：相邻点 < 0.5mm 时沿 x 外推至 ≥0.5mm（MCP 退化阈值 0.25mm）。
- **槽底**：肩起点 → 平底（平底点大 fillet 圆底）。

### 2.2 _slot_cutter_nodes() — fillet 与拉伸

5 组 fillet（radius 由 fr 缩放，cap 上限防退化）：

| 组 | 目标顶点 | 半径公式（fr=1.0 → 实际） |
|---|---|---|
| 齿顶 `rad_dome` | 齿 i: 2+4i, 3+4i | `min(fr×3, r_tip×0.8)` → r≈2.4 |
| 内斜面降 `rad_flank` | 齿 i: 4+4i | `min(fr×1.2, 2.0)` → r=1.2 |
| 连接线 `rad_neck` | 楔入 1, 齿 i: 5+4i | `min(fr×1.0, 1.6)` → r=1.0 |
| 槽底肩 `rad_shoulder` | n_upper−2 | 固定 0.3（r_max 小） |
| 槽底 `rad_bottom` | n_upper−1 | `min(fr×3, bottom×0.9)` → r≈2.1 |

齿顶圆角半径数学公式：
```
r_tip = w_tip / (tan(Tfa/2) + tan(Ufa/2))
```
（两圆弧恰在齿顶平台中点相切 = 完整圆弧顶；×0.8 留平台防端面微边）

### 2.3 slot_fillet_fr_limit() — fr 上限约束

5 组 fillet 全组切线空间约束（OCC fillet2D 失败判据）：
```
r·tan(θ/2) ≤ min(L1, L2)   →   fr ≤ r_max_v / factor
```
cap 不限制 fr 名义值（rad 被 cap 固定后 ≤ r_max 则安全）。

### 2.4 采样与约束（candidate_sampler / sampling_constraints）

- 约束：slot_pitch（节距）、slot_depth（深度+剩料）、slot_depth_ratio（≥0.55×rim_radial）、slot_bottom（槽底不穿）、slot_fillet_space（5 组圆角空间）、slot_teeth_space（齿区占用 ≤ depth−9）。
- `_normalize_slot`：fr clamp 用 slot_fillet_fr_limit。

## 三、参数体系（当前生效值，D15 v9 为例 mouth=8）

| 参数 | 值 | 含义 |
|---|---|---|
| teeth | 2（族间 2-4） | 单侧齿数 |
| depth | 21.2（**slot2d 自然深度**，不撑满） | 槽深（t2 m8=21.2 / t2 m7=18.8 / t3 m6=22.4 / t4 m7=28.1） |
| mouth_half (throat) | 8.0（t2）/ 6.0（t3）/ 7.0（t4） | 口部半宽（按齿数） |
| neck_half | **[0.84,0.64,0.44]×m**（N2 slot2d 认可比例） | 齿根半宽（N3=[0.90,0.68,0.46,0.24] N4=[0.84,0.70,0.56,0.42,0.28]） |
| tooth_height | [0.36,0.30]×m | 齿高（N2 比例） |
| tooth_thickness | 0.16×m | 齿顶平台厚（N2 认可 thick=0.16m） |
| neck_platform | **1.2**（连接线 ~1.25mm） | 连接线径向跨度（太短 0.74mm → 凹口 fr_hi 0.5 < 收窄角 fr_lo 0.64 崩） |
| Tfa / Ufa | **45° / 75°** | 升面(非承力,陡45°)/降面(承力,缓15°) 与径向夹角 |
| fr | ≤ fr_limit（t2=0.97 / t3=1.24 / t4=1.11） | 圆角缩放（**7 组独立系数** ×m×fr） |
| bottom_half | **max(0.44m, neck_last+0.1m)** | 槽底半宽（N2=0.54m：卡榫有外扩落差；N3/N4=0.44m） |

圆角独立系数（7 组，×m×fr）：齿顶 0.12、齿根平台 0.08、齿根凹口 0.10、卡榫肩/外扩/平台 0.08、收窄 0.10。

**`_slot2d_solve_depth`（自然结构，不撑满）**：深度由 mouth/齿数比例自然决定，**绝不因 depth_mm 增大而拉长卡榫底或连接线**（用户指正：为拉深强拉榫底/连接线破坏形状协调、槽不可用）。卡榫底紧凑（段长 1-2mm）、连接线短（~1.25mm）。各族 depth 取自然值，多余深度宁可忽略。

## 四、关键设计决策与权衡

1. **齿面角不对称（磨好值）**：Tfa=45°（升面/非承力，与径向夹角，陡）、Ufa=75°（降面/承力，与径向夹角，缓）——**承力边较非承力边更缓**（γ=90−ufa=15°），连接线共线（颈部斜线，端点偏差 0）。

2. **slot2d 组合比例（用户认可）**：N2/N3/N4 各齿 neck_half/tooth_height/thick 用 slot2d 认可比例 × mouth 缩放（N2 neck=[0.84,0.64,0.44]m、h=[0.36,0.30]m、thick=0.16m），卡榫状槽底（外扩→平台→收窄→平底）。

3. **卡榫底半宽自适**：`bottom_half = max(0.44m, neck_last+0.1m)`。N2 时 neck_last=0.44m=bottom 等高 → 卡榫无落差被压扁、最后齿根到槽底被撑长；0.54m 让卡榫有轻微外扩落差且 OCC 圆角放得下。N3/N4 不受影响。

4. **自然深度，不撑满**：深度由 mouth/齿数比例自然决定（slot2d 参考图），绝不因 depth_mm 拉长卡榫底或连接线。连接线 neck_platform=1.2（~1.25mm，太短则凹口圆角空间不足）。

5. **独立圆角系数 + fr_limit**：7 组圆角独立系数（齿顶>凹口>齿根>卡榫），`slot_fillet_fr_limit` 数值二分求全组安全 fr 上限（单角切线 + 共享段残留 0.26 + 弧长≥0.25）。

## 五、已知问题与待修复点（专家关注）

### ⚠️ P1 — 深槽与形状协调不可兼得（回归自然结构）
- **现象**：为拉深（depth 36/48）曾强行拉长卡榫底（平台段 8mm+）与连接线（5mm+），用户判定榫底过长、形状不协调、槽不可用。
- **落地**：`_slot2d_solve_depth` 回归自然结构（不撑满），深度取 slot2d 自然值（t2 m8=21.2 / t3 m6=22.4 / t4 m7=28.1），卡榫底紧凑（1-2mm）、连接线 ~1.25mm。若需更深的槽，应增大 mouth（自然更深）或增加齿数，而非拉长榫底。

### ⚠️ P1 — 耦合盘孔位与榫槽底部靠近
- **现象**：coupled 族（D24/D25/D26/D28）原孔 pcd 靠近轮缘外，槽底（rim_r−depth）与孔范围重叠 → 布尔微边（MCP 短边）。
- **落地**：孔 pcd 内移（D24=200 / D25=210 / D26=220 / D28=240），使 pcd+hdia/2+间隙 < 槽底半径。

### ⚠️ P2 — 端面微边限制"圆顶"程度
- 齿顶保留平台直线段 + OCC fillet2D 真圆弧（曲率连续）→ 无微边；无法做凸半圆（dialect 无圆弧命令）。

### ⚠️ P2 — 每齿参数未独立
- 各齿共用 slot2d 比例（N2/N3/N4 数组），未实现 HB5965 逐齿完全独立（pitch[i]/height[i]/flank[i]/fillet[i]）。`fir_tree_parametric.py` 有独立参数结构可参考。

### ℹ️ P3 — 槽底圆弧实现
- 卡榫槽底用平台段 + 收窄 + 中心平底（镜像），非"U 形凹圆弧"。
