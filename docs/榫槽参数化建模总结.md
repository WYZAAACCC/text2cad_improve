## 一、目标与方法

为论文"面向航空发动机涡轮盘的自然语言参数化 CAD 建模"生成枞树形榫槽（fir-tree slot）的**确定性参数化几何**（参考几何，非适航件）。采用：

1. **半边轮廓生成 → 镜像 → 闭合**（`fir_tree_slot2d.py`，依据 `docs/榫槽伪代码.md` §20-21）
2. **尖角骨架 → 圆角相切**：先建理论尖角线，再对齿顶/齿根/过渡用 `CreateFillet`（切点距 = R/tan(φ/2)）
3. **主实现**（`param_templates.slot_profile`）：角度驱动齿面角 + 齿根共线 + 顶点 fillet，最终经 validation/runtime/MCP 门产出 STEP

## 二、当前实现架构（param_templates.py）

### 2.1 slot_profile() — 轮廓点生成

```python
slot_profile(teeth, depth_mm, mouth_half, neck_half, lobe_half,
             bottom_half, tfa_deg=80.0, ufa_deg=70.0) -> [points]
```

- **坐标**：x 径向（0 = 槽口 → −depth = 槽底），y 半宽。上侧 `2+4×teeth+3` 点 + 下侧 y=0 镜像。
- **每齿 4 点**：外斜面升（齿顶）→ 齿顶平台 → 内斜面降（齿根）→ 连接线。
- **齿面角角度驱动**（P6 修复）：斜面 x 跨度 `dx = Δy/tan(θ)`，θ = Tfa（外/承力面）/ Ufa（内/非工作面），默认 80°/70°（mon 实测）。
- **齿根共线斜线** `y_neck(x)`：齿根点（内斜面降 + 连接线）沿一条斜线排列（线性穿过楔入点与最后齿根），斜率 ~0.095（5.4°）。
- **neck/lobe**：neck_half=1.1×throat（4.4）、逐齿递减 0.25×throat（下限 1.5）、lobe=2.25×throat（9.0）、逐齿衰减 0.25×throat。
- **短边修正**：相邻点 < 0.5mm 时沿 x 外推至 ≥0.5mm（MCP 退化阈值 0.25mm）。
- **槽底**：肩起点 → 平底（平底点大 fillet 圆底）。

### 2.2 _slot_cutter_nodes() — fillet 与拉伸

5 组 fillet（radius 由 fr 缩放，cap 上限防退化）：

| 组 | 目标顶点 | 半径公式（fr=1.0 → 实际） |
|---|---|---|
| 齿顶 `rad_dome` | 齿 i: 2+4i, 3+4i | `min(fr×3, r_tip×0.8)` → r≈2.4 |
| 内斜面降 `rad_flank` | 齿 i: 4+4i | `min(fr×1.2, 2.0)` → r=1.2 |
| 连接线 `rad_neck` | 楔入 1, 齿 i: 5+4i | `min(fr×1.0, 1.6)` → r=1.0 |
| 槽底肩 `rad_shoulder` | n_upper−2 | 固定 0.3（r_max 小） |
| 槽底 `rad_bottom` | n_upper−1 | `min(fr×3, bottom×0.9)` → r≈2.1 |

齿顶圆角半径数学公式：
```
r_tip = w_tip / (tan(Tfa/2) + tan(Ufa/2))
```
（两圆弧恰在齿顶平台中点相切 = 完整圆弧顶；×0.8 留平台防端面微边）

### 2.3 slot_fillet_fr_limit() — fr 上限约束

5 组 fillet 全组切线空间约束（OCC fillet2D 失败判据）：
```
r·tan(θ/2) ≤ min(L1, L2)   →   fr ≤ r_max_v / factor
```
cap 不限制 fr 名义值（rad 被 cap 固定后 ≤ r_max 则安全）。

### 2.4 采样与约束（candidate_sampler / sampling_constraints）

- 约束：slot_pitch（节距）、slot_depth（深度+剩料）、slot_depth_ratio（≥0.55×rim_radial）、slot_bottom（槽底不穿）、slot_fillet_space（5 组圆角空间）、slot_teeth_space（齿区占用 ≤ depth−9）。
- `_normalize_slot`：fr clamp 用 slot_fillet_fr_limit。

## 三、参数体系（当前生效值，throat=4 为例）

| 参数 | 值 | 含义 |
|---|---|---|
| teeth | 2（族间 2-4） | 单侧齿数 |
| depth | 33（≥0.55×rim_radial） | 槽深 |
| throat | 4.0 | 喉部半宽 |
| mouth_half | throat | 口部半宽 |
| neck_half | **1.1×throat = 4.4** | 口部齿根半宽 |
| lobe | **2.25×throat = 9.0** | 口部齿顶半宽 |
| neck 递减 | 0.25×throat/齿（下限 1.5） | 齿根逐齿收窄 → 齿根共线斜率 |
| Tfa / Ufa | 80° / 70° | 外/内斜面角（与径向 x） |
| fr | ≤ slot_fillet_fr_limit | 圆角缩放主参数 |
| bottom | 0.875×throat = 3.5 | 槽底平底半宽 |
| shoulder | 1.25×throat = 5.0 | 槽底肩半宽 |

## 四、关键设计决策与权衡

1. **齿面角角度驱动**：`flank_angle_deg` 原为死参数（函数体零引用，实际齿面角 66-81° 由硬编码比例决定）。改为 Tfa/Ufa 显式驱动（`dx=Δy/tanθ`），默认 80/70 保持 mon 齿形。

2. **齿根共线斜线**：齿根沿 `y_neck` 一条斜线（用户要求"连接线斜率大、榫中部不窄"）。斜率 ~0.095（neck 1.1t→1.5）。

3. **圆顶圆底（数学公式半径）**：
   - 齿顶：fillet 双圆弧，`r_tip = w_tip/(tan(Tfa/2)+tan(Ufa/2))` 使两圆弧在平台中点相切。
   - 槽底：平底点大 fillet（直线过渡段长 → r_max 大）。
   - **×0.8 留 ~20% 平台**：折中——polyline 曲线在轮缘端面产生微边，平台直线段无微边。

4. **端面微边（MCP 门与"圆顶"的核心矛盾）**：轮缘端面 z=−rim_half 处，任何曲线（fillet 大圆弧、凸半圆折线）与端面的布尔交线会产生 <0.25mm 微边，被 MCP `check_degenerate_geometry` 拦截。已验证：
   - 齿顶 fillet 相接（无平台）→ 960 微边；留平台 0.69mm → 0 微边
   - 凸半圆折线（5/9 点内嵌）→ 1920 微边（折点 C1 不连续）
   - 折点加小 fillet → 微边反增
   - **平台直线段 + fillet 真圆弧**（OCC fillet2D 曲率连续）→ 无微边

5. **占用平衡**：neck 大（点 9/14 距离宽）→ 斜面占用 occ_base 小 → 平台 w_tip 大 → 齿顶 fillet 大 → 端面微边。通过 **lobe 增大（2.25×throat）** 补偿 occ_base，使 w_tip ≤4.62（无微边阈值）。

## 五、已知问题与待修复点（专家关注）

### ⚠️ P1 — 端面微边限制"圆顶"程度
- **现象**：齿顶无法实现完全圆弧顶（凸半圆/无平台），必须留 ~20% 平台直线段以避免轮缘端面 z=−30 处的 <0.25mm 布尔微边。
- **技术根因**：当前 CAD dialect 只有 `add_polyline`（折线）+ `fillet_sketch`（切角圆角），无凸圆弧命令。折线 C1 不连续在端面布尔产生微边；fillet 真圆弧可做凹圆角但无法做凸半圆。
- **候选方案**：① dialect 引入圆弧命令（add_arc）；② 凸半圆 + 端面裁剪/分段；③ 接受平台。

### ⚠️ P1 — 圆角可放空间与连接线斜率冲突
- **现象**：连接线陡（斜率大）→ 连接线短 → 齿根凹角（点 4/5/8/9）fillet 可放空间 r_max 小，圆角被迫小。
- **表现**：连接线 45° 时 fr 上限被压到 0.44；当前 0.25×throat 递减（斜率 0.095）下 fr 上限 ~1.25。
- **候选**：齿根凹角改用凹圆弧点内嵌（不受 fillet r_max 限制），但需解决端面微边。

### ⚠️ P2 — 齿顶"圆顶" vs 平台残留
- 当前平台残留 0.9mm（×0.8 系数），用户嫌"不是圆弧状"。要更圆则平台更小 → 端面微边。两难。

### ⚠️ P2 — 每齿参数未独立
- 当前所有齿共用 neck/lobe 衰减（全局 + 线性），未实现 HB5965 逐齿独立（pitch[i]/height[i]/flank[i]/fillet[i]）。`fir_tree_parametric.py` 已有独立参数数据结构（`FirTreeParams`），可参考。

### ℹ️ P3 — 槽底圆弧实现
- 槽底用平底点大 fillet（r≈2.1），非"U 形凹圆弧"。点内嵌凹半圆曾因与过渡段尖角导致 solid 无效，已回退。
