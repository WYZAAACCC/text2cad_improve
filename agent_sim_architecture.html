自动仿真 Agent 架构

三个 LLM Agent 分别决定承力面、网格密度与物理量；确定性 Harness 负责校验、测量与求解。Agent 负责判断，Harness 负责证伪。

01系统架构

系统分为四层。关键设计是：Agent 只做判断，不做计算，也不接触求解器。它通过工具获取几何事实并输出结构化意图；所有数值计算、文件生成与求解器调用都发生在确定性代码里。每一层之间都有校验门。

02端到端流程

从左到右五个阶段。菱形是校验门——每条门都是 fail-closed 的：不通过就停，不会降级执行。

03网格 Agent 的反馈闭环

这是整个系统里唯一一个Agent 能看到自己方案真实代价的地方。Agent 提出加密方案后，Harness 真的去生成网格，把实测数字回传，Agent 据此修订。这是把「看起来专业的方案」变成「经过验证的方案」的关键。

载荷方向规则

载荷 Agent 从物理判断选用哪条规则，而不是固定用一条：

direction_rule物理含义载荷表输出
radial_outward_from_rotation_axis等效径向体力，每个节点沿轴向外推F,n,FX
flank_surface_normal榫头压在齿面上，力沿齿面内法向F,n,FX + F,n,FY
两种规则的差别不是细节。齿面法向偏径向约 44°，纯径向规则会把牵引力放错方向。同网格实测：齿面峰值应力 178.2 → 163.2 MPa（−8.4%），孔缘峰值几乎不变。合力仍被精确钉在 10,000 N。

代码里还加了一条方向合理性检查：法向符号若选反，合力会朝内——而幅值检查发现不了，因为缩放总会把合力大小钉准。
