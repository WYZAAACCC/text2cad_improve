# 榫槽 LLM 生成 vs 确定性生成器 — Prompt 迭代总结

> 日期：2026-08-03
> 目标：参数化 prompt → LLM 生成槽轮廓点，与确定性生成器逐点对比，迭代直到高概率完全一致

---

## 一、迭代历史（V1~V12）

| 版本 | 策略 | 最佳结果 |
|------|------|---------|
| V1 | 纯公式 prompt | LLM 视觉近似（误差大） |
| V2 | 公式 + tan 值表 | 更差（prompt 过复杂） |
| V3 | 2齿 few-shot 示例 | 结构对、坐标近似（T06 0.21mm） |
| V4 | 公式+tan+点数公式 | 点数结构错（40点） |
| V5 | 双示例(2+3齿) | T03/T02 EXACT（照抄示例） |
| V6 | 双示例+tan | y 对、x 累积误差大 |
| V7 | **dx 预计算** | T04 0.034mm（近 EXACT） |
| V8 | 双示例+dx+累减规则 + **retry 反馈精炼** | T04 3/3 (100%)，整体 50% |
| V9 | 只输出上侧 | 全失败（LLM 不习惯半量） |
| V10 | 参数表+dx表前置 + 强"禁止近似" | **T09 3/3 (100%)** |
| V11 | 三示例覆盖角度 | 全失败（prompt 过长） |
| V10+逐齿反馈 | 精确指出错误齿 | 不稳定，T09 掉到 1/3 |

| 组合 | 特征 | 成功率 |
|------|------|--------|

| T07 (缓齿面50°) | 新角度、dx值大 | 0% |

## 三、核心发现（LLM 算术精度本质限制）

1. **LLM 可靠的部分**：点数、结构、顺序、y 坐标（`neck+tooth_height` 简单加法）——已稳定解决
2. **LLM 不可靠的部分**：**x 坐标的逐齿精确累加**（除法 `dx=height/tan(flank)`）。即使程序预计算 dx 值，LLM 仍偶发用整数近似
3. **参数值近似倾向**：LLM 连 neck=2.6 都写成 3.0（`max_dy=0.5` 持续出现）——根本的不精确倾向
4. **误差随 dx 值增大**：小齿高(dx<2mm)误差 <0.05；缓齿面(dx≈5-6mm)误差 3-14mm
5. **反馈/retry 不稳定**：有时收敛（T04 2轮 EXACT），有时 LLM 更乱（点数改变）
6. **prompt 长度敏感**：示例越多越差（V11 三示例全失败）；1 个示例最优

---

## 四、结论

**纯 prompt 让 LLM 精确算术有本质困难**——LLM 的结构/设计能力可靠，但逐点浮点算术（尤其大 dx 值）随机失败。多次测试表明无法通过 prompt 迭代达到"高概率完全正确"。

**达到 100% 的可靠路径 = 混合方案**：
> LLM 负责结构理解/布局决策（每齿的关键 x 位置），程序用确定性公式精确生成点
> - LLM 只输出 teeth_count 个 x 起始位置（算术量最小）
> - 程序保证几何精确（dx 计算、y 映射、底部、镜像）
> - "完全正确"由程序保证，LLM 做设计决策

**纯 prompt 可用范围**：标准角度(≈66.7°/60°)、小齿高、常规参数——V10 可达 100%；非常规角度/大跨度建议程序兜底。
